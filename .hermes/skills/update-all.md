## 문제 상황
공장(factory) 설치 변경 사항을 12개 프로젝트에 광범위하게 전파할 때, 실제 영향 범위와 각 프로젝트의 현재 상태를 확인 없이 진행하려 하거나, 전파 스크립트(`update-all.sh`)가 정확히 무엇을 다시 쓰는지 추측으로 실행하는 경향.

## 규칙
- [ ] `update-all.sh` 스크립트의 동작을 사전에 **실행하지 말고 확인**: 복사만 하는지, 파일을 다시 쓰는지, 어느 파일들인지
- [ ] 전파 대상 12곳 각각에 **지금 돌고 있는 루프나 커밋되지 않은 관련 변경이 있는지 스캔**
- [ ] 마지막 전파 이후 **쌓여 있는 변경 목록을 한 번에 확인**한 뒤 전파 결정
- [ ] 추측하지 말고 **문서·스크립트 코드·git 상태로 확인**
- [ ] 전파 전에 **롤백 계획 또는 영향 범위 보고서** 작성

## 근거
- 감지 횟수: 3회 (계획 1·2 구현 중, 전파 단계에서 매번 "확인이 필요하다"는 판단)
- 패턴 키: update-all.sh
- 세션 인용: "전파할 때 실제로 무엇이 바뀌는지는 추측하지 않고 확인하겠습니다"
