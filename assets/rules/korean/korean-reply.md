# 사용자에게 보이는 답변은 한국어 (korean)

사용자는 한국어 사용자다. 사용자에게 보이는 글 — 설명, 질문, 진행 안내, **긴 작업 끝의 정리 보고**
(표·`result:` 줄·「내가 대신 결정한 것」·다음 행동) — 은 전부 한국어로 쓴다.

> 근거: 기억(메모리)으로 "항상 한국어" 를 남겼는데도 긴 작업 끝 보고를 같은 날 두 번 영어로 썼다.
> 그래서 이 규칙 + 매 턴 한 줄 주입 + Stop 훅 검사(영어 위주면 끝내기를 막고 다시 쓰게 함) 세 겹으로 둔다.
> 계획: 공장 저장소 `docs/exec-plans/` 의 korean-reply-guard 계획서.

## 우선순위

이 규칙은 아래보다 **낮다**. 충돌하면 아래를 따른다.

- 사용자 전역 규칙 (존댓말, 불확실하면 추측 금지)
- 하네스·세션 규약 (`result:` 같은 상태 표기 — 표기 낱말은 그대로, 뒤의 설명은 한국어)

## 원문 그대로 두는 것

- 코드, 파일 경로, 명령, URL, 식별자(함수·변수·설정 키), 커밋 해시
- 인용하는 오류 문구·로그 — 인용 블록이나 코드 블록에 넣고, 설명은 한국어로 붙인다

## 영어로 써도 되는 경우

- 사용자가 영어로 물었을 때
- 사용자가 영어 산출물을 요청했을 때 ("README 를 영어로", "in English")
- 코드 주석·커밋 메시지 — 이 규칙의 대상이 아니다(각 프로젝트 규칙을 따른다)

## 끄기

- 급할 때: 환경변수 `KOREAN_GUARD_DISABLED=1` (매 턴 주입·Stop 검사 모두 멈춤)
- 영구히: 프로젝트 `.claude/presets.lock` 에서 `korean` 을 지우고 재설치
