# 움직임 종류별 구현 기법

먼저 관찰 기록의 「본 것」 에서 **면이 휘는가** 를 본다. 휘지 않으면 가벼운 기법으로 충분하고, 휘면 천 물리로 간다.

| 영상에서 본 것 | 기법 | 출발점 |
|---|---|---|
| 카드가 기울며 따라오고 놓으면 튕겨 제자리 (면은 평평) | CSS transform + JS 스프링(감쇠 진동) · 경첩은 `transform-origin` | 직접 — 스프링 `v += (-k·x − c·v)·dt` |
| 흰 면끼리 가까우면 녹아 붙고 멀어지면 끊어짐 | SVG goo 필터(흐림 + 알파 문턱), 글자는 위 층에 따로 | `feGaussianBlur stdDeviation≈6` + `feColorMatrix … 0 0 0 22 -9` |
| 절취선 구멍이 동그랗게 벌어졌다 옆으로 늘어남 (평면) | SVG 타원 + 이어진 종이띠 path 를 매 프레임 다시 그림 | — |
| 종이·천처럼 접히고 비틀림, 세로축으로 휘며 뒤집힘, 찢긴 조각을 들고 다님 | **Verlet 천 격자 + WebGL** (앞·뒷면 그림 · 빛) | [../assets/cloth/](../assets/cloth/) `cloth.js` · `render.js` |

## 천 물리 구성 (assets/cloth)

파일 넷으로 나눈다 — 예시는 앞의 둘만 싣고, 뒤의 둘은 프로젝트 내용이 들어가 매번 새로 쓴다.

1. `cloth.js` — 격자 점(위치·이전 위치·쉬는 자리), 제약(가로·세로·대각 굳기 1, 두 칸 건너 접힘 저항), 조각 둘(본권·반쪽권)을 절취 고리로 묶음. 한 걸음 = 적분 → 쉬는 자리 스프링 → 제약 12회 → 찢김 판정
2. `render.js` — WebGL1. 정점에서 원근(초점 900px), `gl_FrontFacing` 으로 앞/뒤 그림을 고르고 뒤는 `u → 1−u` 로 뒤집어 읽음. 밝기 `0.5 + 0.6·max(n·L, 0)`(평평하면 1.0), 옅은 반사. 미리곱 알파 + 깊이 시험
3. `paint.js`(프로젝트마다) — 2D 캔버스에 앞·뒷면 그림을 토큰 색·글꼴로 그림. 둥근 모서리는 투명, **절취선 자리에 구멍을 투명으로 뚫으면** 쉴 땐 점선, 찢기면 반쪽씩 물린 가장자리가 공짜로 나온다. 글꼴은 `document.fonts.load` 뒤에 그린다
4. `app.js`(프로젝트마다) — 60Hz 고정 걸음(한 프레임 최대 4걸음, 밀린 걸음은 버림), 포인터: 투영한 점 중 가장 가까운 것을 잡고(칸 1.2개 안), 잡은 점을 카메라 쪽으로 24px 들어 접힘이 앞으로 나오게, 상태에 따라 쉬는 자리 스프링 세기를 바꿈

| 상태 | 본권 스프링 | 반쪽권 스프링 | 이유 |
|---|---|---|---|
| 놓음 | 0.06 | 0.06 | 출렁이다 제자리 |
| 본권을 끔 | 0.008 | 0.008 | 거의 손을 따라옴 |
| 반쪽권을 끔 | 0.25 | 0 | 본권을 붙잡아 절취선에 힘이 모임 |
| 뒤집는 중 | 0.14 | 0.14 | 조금 늦게 따라와 휘어 보임 |

## 천 물리 함정 (2026-10-22 검증이 잡은 것)

| 증상 | 원인 | 처방 |
|---|---|---|
| 반쪽권을 끝까지 당겨도 찢김 0% | 절취 고리를 다른 제약과 같은 굳기로 둠 → 당긴 힘이 격자 전체로 흩어짐 | 절취 고리만 무르게(0.25) — 가장 약한 곳에 힘이 모인다 |
| 92%에서 멈추고 마지막 칸이 남음 | 마지막 칸은 경첩처럼 돌기만 해 고리가 늘어나지 않음 | 끝 2칸이 남았을 때 반쪽권 윗줄 가운데가 폭의 25% 넘게 돌아가면 마저 찢김 |
| 뒤집기가 판처럼 단단히 돔 | 쉬는 자리를 세로축으로 돌리기만 함 | 뒤집는 동안 아래로 갈수록 뒤로 처지게 `z += ((y+h/2)/h)²·sin(각)·0.35h` |
| 완전 평면에서 접힘이 화면 밖으로 안 나옴 | 대칭 | 시작 z 에 ±0.3px 들뜸, 잡은 점을 카메라 쪽으로 듦 |
| 놓을 때 튀어 나감 | 잡은 점의 이전 위치를 안 갱신 | 잡은 동안 매 걸음 `prev = pos; pos = 손` |
| 탭을 숨겼다 오면 한꺼번에 튐 | 밀린 시간을 다 걸음으로 | 한 프레임 최대 4걸음, 남는 시간은 버림 |
| 덜 찢고 놓았을 때 다시 붙음 | — | 종이는 다시 붙지 않는다(찢긴 칸 유지). 영상에 그 장면이 없으면 사용자에게 확인 |

## 가볍게 해도 되는 것

- 무지개 홀로그램·소리 같은 장식은 프로젝트 색 규칙과 부딪히면 빼고 「가져오지 않을 것」 에 적는다 — 움직임이 핵심이다
- 영상 속 앱 배경(흐린 색 덩어리 등)은 가져오지 않는다
