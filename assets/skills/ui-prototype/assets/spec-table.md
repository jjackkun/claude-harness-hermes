## 기계 판독 규약 (`scripts/check_spec.py` 가 이대로 읽는다)

- 표는 주석 표지 `<!-- ui-prototype:spec v1 -->` **바로 아래 첫 표**. 칸 순서·이름은 위와 똑같이 고정 — 다르면 검사가 읽기를 멈춘다(종료 2).
- `범위`: `1차` 는 시안에 반드시 등록, `2차` 는 등록 안 해도 됨(등록하면 검사 대상). 처음엔 핵심 고리만 1차로 둔다.
- `그룹`: 왼쪽 화면 목록의 묶음 이름 (보통 역할 — 참여자·운영자). 묶음 순서는 `scripts/config.js` 의 `groups`.
- `번호`: `^[A-Z]{1,4}-[0-9]{2}[a-z]?$` — 영문 대문자 1~4 · `-` · 숫자 2 · 소문자 0~1 (예 `SD-01`, `EB-01a`). 주소 `#번호` 로 바로 열리는 글자다. 같은 번호 두 번 금지.
  문서 번호가 이 규칙에 안 맞으면(한글·공백·세 자리) 새 번호를 붙이고 **원래 번호는 근거 칸에** 남긴다.
  같은 화면의 상태별 장면은 같은 번호에 접미사: `EB-01a`(모집중) · `EB-01b`(진행중).
- `상태`: 같은 화면의 상태 이름. 없으면 `-`.
- `틀`: `phone` · `tablet` · `browser` · `desktop` 중 하나. 화면 파일의 `frame`(없으면 `config.js` 의 기본 틀)과 같아야 한다.
- `행동`: `라벨→번호` 를 `;` 로 잇는다. 없으면 `-`. 화면에 그 번호를 가리키는 `data-go` 버튼이 있어야 한다.
  시트 열기처럼 **같은 화면 안의 변화**는 자기 번호를 가리켜도 된다 (검사에서 뺀다).
- `근거`: 요구 ID(`[A-Z]+-[0-9]+`)·문서 위치·`가정 P<n>` 를 `,` 로 나열.
- `<!-- ui-prototype:requires ... -->`: 이번 범위에서 화면으로 보여야 하는 요구 ID 를 공백으로 (예 `<!-- ui-prototype:requires SADA-01 COMMON-03 -->`).
  하나라도 어느 행 근거에도 없으면 실패. 대조할 요구가 없으면 표지만 둔다.
