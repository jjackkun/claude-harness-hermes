# 예시 시안 명세표

> 시작 틀에 든 예시 장면 3개의 명세표. 실제 시안에서는 `assets/spec-table.md` 양식으로 새로 쓴다.
> 왼쪽 화면 목록과 오른쪽 화면은 둘 다 이 표에서 나온다. 기능·흐름을 바꿀 때는 이 표부터 고친다.

<!-- ui-prototype:spec v1 -->
| 범위 | 그룹 | 번호 | 이름 | 상태 | 틀 | 보여 주는 것 | 행동 | 근거 |
|---|---|---|---|---|---|---|---|---|
| 1차 | 사용자 | EX-01 | 목록 | - | phone | 항목 목록 | 목록 항목→EX-02 | 가정 P1 |
| 1차 | 사용자 | EX-02 | 상세 | - | phone | 대표 사진, 설명, 확인 시트 | 확인하고 웹 화면 보기→EX-03; 뒤로→EX-01 | 가정 P1 |
| 1차 | 관리자 | EX-03 | 관리 목록 | - | browser | 항목 표 | 앱 화면으로→EX-01 | 가정 P2 |
<!-- ui-prototype:requires -->

## 가정

- P1 — 사용자 화면은 목록 → 상세 → 확인 순서다 (문서 없음, 견본용)
- P2 — 관리자는 같은 항목을 웹 표로 본다 (문서 없음, 견본용)
