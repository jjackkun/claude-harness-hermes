# watch — 영상을 받아서 끝까지 보고 정리한다

## 왜 있나

2026-11-16, 유튜브 쇼츠를 "확인해봐" 로 받고 제목·설명란만 읽고 답했다가 "영상을 안봤어???" 를 들었다.
설명란은 링크뿐인 경우가 많고, 쇼츠는 28초 안에 말과 화면 글자로만 요점을 전한다.
**자막을 끝까지 읽고 장면을 보기 전에는 내용을 말하지 않는다.** 못 봤으면 못 봤다고 첫 줄에 쓴다.

## ① 받기

```bash
W=<이 스킬 폴더>/scripts/watch.sh
OUT=.harness/out/watch-<영상 ID>
bash $W fetch "<URL>" $OUT          # info.json · 자막(vtt) · 720p 이하 영상
bash $W info  $OUT                  # 제목 · 채널 · 길이 · 설명 · 챕터
```

- 파일을 받았으면 받기를 건너뛰고 ③으로 간다(자막이 없으니 화면과 소리 정보만 있다고 보고에 쓴다)
- 자막 기본 언어는 `ko,ko-orig,en-orig`(원어). 다른 언어가 필요하면 셋째 인자로 준다
- 영상 본체가 실패해도 자막·정보로 진행한다. 실패 이유는 `$OUT/fetch-video.log` 의 ERROR 줄에 있다
- 403·"n challenge" 가 나면 yt-dlp 가 유튜브 변화를 못 따라간 것이다 — 스크립트가 매번 최신판을 받으므로 다시 돌린다.
  **전역 `pip install yt-dlp` 를 먼저 권하지 않는다**

## ② 자막 끝까지 읽기

```bash
bash $W text $OUT/video.ko.vtt > $OUT/transcript.ko.txt
```

- `[MM:SS] 본문` 을 **처음부터 끝까지** 읽는다. 긴 영상은 나눠 읽되 건너뛰지 않는다
- 자동 자막은 고유명사·숫자를 틀리게 받아 적는다. 화면 글자와 다르면 화면을 믿고, 다르다는 사실을 부록에 적는다
- 자막이 없으면 "자막 없음" 을 보고 첫 줄 근처에 쓴다. 장면만으로 추정한 내용은 추정이라고 쓴다

## ③ 장면 보기

```bash
bash $W frames $OUT/video.mp4 $OUT/frames 2     # 2초마다 한 장 → 8장 묶음
```

- 간격: 쇼츠 1~2초 · 슬라이드 강의 5~30초 · 화면 시연 2~5초. 묶음(`$OUT/frames/sheets/`)을 **전부** 읽는다
- 화면 글자(자막 박스·슬라이드 표·코드)는 자막에 없는 정보다. 숫자·표는 화면에서 옮긴다
- 간격 사이에만 지나간 화면은 못 본 것이다 — 부록에 그렇게 적는다. 중요한 순간은 간격을 줄여 다시 뽑는다

## ④ 답하기

사용자가 "확인해봐" 처럼 짧게 물으면 채팅으로 답한다. 순서:

1. 첫 줄: 영상이 말하는 것 한 문장
2. 영상 내용 — 말한 순서대로, 시각 `(MM:SS)` 을 붙여서. 말한 것과 화면에 보인 것을 구분한다
3. **우리 프로젝트와의 접점** — 이미 있는 것 / 비어 있는 것 / 그대로 옮길 수 없는 것. 코드·문서를 실제로 확인한 뒤 쓴다
4. 확인한 방법 — 자막 몇 줄을 읽었는지, 장면 몇 장을 봤는지, 못 본 것

## ⑤ 기록 남기기 (사용자가 원하거나, 프로젝트 결정의 근거가 될 때)

`docs/videos/YYYY-MM-DD-<slug>/<slug>.md` 에 남긴다. 기존 기록과 같은 틀이다:

```text
# <영상이 말하는 것 한 줄>
## 개요            — 제목·채널·길이·URL·한 문단 요약
### 타임라인       — 시각별 한 줄
## 1. … ## N.     — 본문(영상 순서, 절 제목에 시각)
## 걸러 들어야 할 부분 — 주장과 근거가 맞지 않는 곳, 홍보
## 본 프로젝트와의 접점 — 이미 있는 것 / 비어 있는 것 / 옮길 수 없는 것
## 부록 — 확인 방법과 한계 — 자막 언어·줄 수 · 장면 간격·장 수 · 못 본 것 · 도구 버전
```

- 같은 폴더에 `transcript.<언어>.vtt`(원본)와 `transcript.<언어>.txt`(정리본)를 둔다. 장면은 고른 것만 `screenshots/` 에
- 영상 원본(mp4)은 저장소에 넣지 않는다. 사용자가 둔 파일은 그 자리를 가리킨다

## 하지 않는 것

- 제목·설명란·썸네일만 보고 내용을 말하기
- 받기가 막혔다고 추측으로 채우기 — 막힌 단계와 오류 줄을 그대로 보이고 멈춘다
- 영상의 주장을 사실로 옮기기 — "영상에 따르면" 으로 쓰고, 우리가 확인한 사실과 구분한다
