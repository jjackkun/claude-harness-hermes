논의 중에는 질문에 답만 하고, 답 끝에 "~해 볼까요 / 시험해 보겠습니다" 같은 실행 제안을 붙이지 않는다. 실행은 사용자가 시킬 때만 한다.

**Why:** 2026-11-18 게임개발 논의에서 답마다 "다음 행동: 시험해 볼지 정해 주십시오" 를 붙였다가 "자꾸 뭐 할려고하지말고. 대화하자고." 를 들었다. 같은 날 "뭘 푸시해" 핀잔도 같은 뿌리다([[feedback-no-push-suggestion-mid-discussion]]).

**How to apply:** 사용자가 묻는 말(되나/뭐야/차이가 뭐야)에는 첫 줄에 예/아니오와 근거만. adhd 규칙의 "마지막은 다음 행동 하나" 는 논의 중에는 "없습니다" 로 두거나 생략한다. 질문을 되묻는 것도 꼭 필요할 때만.
