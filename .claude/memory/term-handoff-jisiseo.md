handoff envelope 의 한국어 용어는 **"봉투"** 로 유지한다. 2026-09-18 사용자가 "지시서" 로 바꾸자고 했다가, 문서 237곳 치환 범위와
"제안 봉투(제안서)" 와의 구분 문제를 듣고 "그럼 봉투라고 하자" 로 되돌렸다.

**Why:** 이름을 바꾸는 비용(문서·스킬·원장 237곳, 두 뜻 분리)이 이해의 이득보다 컸다. 문제는 이름이 아니라 첫 설명이 없었던 것.

**How to apply:** 계속 "봉투" 라고 쓰되, 사용자에게 처음 언급할 때는 "봉투(= goal·done_when·inputs·기한을 적은 업무 지시 한 장)" 처럼
한 번 풀어 준다. 코드 식별자(`handoff`·`envelope`)·문서는 그대로. 관련: [[hermes-agent-skill]]
