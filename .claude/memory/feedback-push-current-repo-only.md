"전체 푸시해" 를 모든 프로젝트로 넓혀 읽지 않는다. 지금 작업 중인 저장소(공장)에서 커밋이 남았으면 그것만 올린다.

**Why:** 2026-10-02 사용자가 "전체 푸시해" 라고 했을 때 공장의 백로그 문서 하나를 뜻했는데, 모든 프로젝트를 점검해 terminal-shipping 에서 사용자 본인의 기능 커밋 3개(`372ba157..11358747`)를 GitLab main 에 올렸다. 사용자: "니가 다른 프로젝트 푸시를 왜해". 그 저장소는 Jenkins 배포 설정이 있어 배포를 일으켰을 수 있고, 되돌리려면 강제 푸시뿐이라 되돌릴 수 없다.

**How to apply:** 푸시 전에 `pwd` 의 저장소만 대상으로 삼는다. 다른 프로젝트의 앞선 커밋은 보고만 하고 올리지 않는다(전파 커밋을 올리라는 말이 따로 있을 때 제외). 모호하면 "공장만 올립니까" 한 줄로 확인한다. 관련: [[feedback-propagate-means-commit-push]] — 전파 때 소우주 설치 커밋을 올리는 것은 전파를 시킨 경우에만이다.
