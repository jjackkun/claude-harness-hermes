2026-09-19 agent-hire-form 시연에서 조직 정의 폼·입사 폼을 AskUserQuestion 으로 연달아 띄우자
"자꾸 의미 없는 질문들을 하고 있어" 라고 중단시켰다. 조직 정의 답도 "둘 다, 무엇이든 가능해야 해(개미군단도)" 였다.

**Why:** 템플릿 선택지는 사용자에게 정보가 아니라 관문으로 느껴진다. 값은 사용자가 이미 자유롭다고 정했다.

**How to apply:** 폼은 사용자가 요청한 스킬 문서 안의 절차로만 두고, 대화에서는 필수 하나(이름 등)만 산문으로 묻는다.
답에 "둘 다·무엇이든" 이 나오면 그 축은 더 묻지 않고 합쳐서 진행한다. [[term-handoff-jisiseo]]

**예외 — 정해진 선택지에서 하나를 고르는 결정은 폼으로 묻는다 (2026-10-07).**
커밋 훅이 `[ASK]` 로 "폼 하나에 묶어 물어라"(keep/drop/나중에)고 지시했는데, 위 규칙을 넓게 적용해
평문으로 "셋 다 지워라고 답해 주십시오" 라고 물었다. 사용자: "왜 이걸 선택지로 안주고 갑자기 평문으로 이런식으로 묻는거야.."
폼을 띄우자 바로 답했다.

- 위 금지는 **값이 자유인 것을 템플릿으로 연달아 묻는 것**에 대한 것이다(내 해석). 선택지가 실제로 닫혀 있고
  훅·스킬이 폼을 지시하면 폼으로 묻는다.
- 폼을 띄우기 전에 항목의 **실제 내용을 먼저 조회**해 질문에 넣는다 — `hermes-ask.py list` 는 ID 만 보이므로
  `hermes-privacy-review.py list` 로 내용을 본다. 내용을 모른다고 폼을 건너뛰지 않는다.
