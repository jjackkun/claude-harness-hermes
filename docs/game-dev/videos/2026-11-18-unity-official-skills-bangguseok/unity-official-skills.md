# 유니티 공식 스킬 31개로 3D 서바이벌 게임 한 판

## 개요

- 제목: 유니티 클로드 코드로 게임 만들기, 공식 스킬 31개 깔고 3D 서바이벌 게임까지 한 줄로
- 채널: 방구석컴퍼니 · 길이: 10분 31초 · 올린 날: 2026-09-29 (촬영 2026-09-22)
- URL: https://www.youtube.com/watch?v=s6cGZRgbqXw

유니티를 한 번도 깔지 않은 컴퓨터에서 유니티 공식 스킬(`Unity-Technologies/skills`)을 명령 한 줄로 넣고, 유니티 명령창으로 설치·로그인·프로젝트 생성까지 한 뒤 3D 서바이벌 게임 한 판을 만든다. Claude Code Game Studios 와는 **다른 저장소**다. 유니티 MCP(실시간 연결 서버)는 구독이 필요해서 쓰지 않았다.

### 타임라인

- 00:00 완성 게임: 오크 떼, 레벨업 카드, 중간 보스 예티. 사람은 로그인·확인창·방향 정하기만
- 00:36 돈 드는 곳: 스킬 무료(깃허브 공개) · Claude Code 요금 별도 · 유니티 개인용 무료(한 해 매출+투자금 2억 9천만 원 아래) · 실시간 연결 서버는 구독 필요 → 안 씀
- 01:08 `npx skills add Unity-Technologies/skills` — 스킬 폴더가 프로젝트로 들어옴. 스킬은 이름과 "언제 쓰는지" 한 줄만 먼저 읽힘
- 01:38 31개 중 27개만 설치(설치기가 머리말을 못 읽음). 영상에 따르면 지금은 고쳐짐. Node.js 가 없으면 아무것도 안 됨
- 02:19 유니티 명령창 설치: 윈도우 앱 설치 명령(winget 판)은 4.1GB 받고 두 번 실패(상자 안에 갇힌 앱이라 진짜 폴더에 못 씀) → 공식 설치 스크립트로 성공. 편집기 받기 6분·설치 3분
- 02:56 사람 손 1: `unity auth login` → 브라우저 로그인(첫 번째는 시간 초과). 개인용 허가 — 편집기 먼저, 허가 나중(반대면 실패)
- 03:28 빈 프로젝트 1분 20초. "명령을 받아 주는 부품"을 넣고 열기 → 90초 뒤 준비됨 → Claude 가 유니티 안에서 코드를 직접 돌림. 3D 프로젝트는 렌더 방식 변경 확인창 OK 가 필요(사람 손 2)
- 04:05 첫 시도 2D 도트: 픽셀 고정 스킬이 카메라를 맞춤. 타일 스킬은 이름·격자 종류를 말할 때까지 기다림. 그림 파일이 없어 코드로 사각 타일을 찍어 바닥 4,800개
- 05:08 방향 전환: 코드로 찍은 도트는 "눈이 안 갔다". 무료 도트 팩을 붙여도 같음 → 3D 로. UI 가 하늘색 덩어리면 테마 파일 연결이 빠진 것
- 05:43 무료 3D 팩 2개(CC0): Kenney Mini Dungeon(바닥·벽·기둥·상자·기사, 걷기·공격·죽기 동작) · Quaternius 몬스터(큰 몬스터 16종)
- 06:15 Assets 폴더에 복사 → 새로 읽기. 스킬 3개로 던전: 길찾기(내비 메시, 적이 0.25초마다 경로 재계산 — 화면 글자 기준, 자막은 "0.2") · 화면 분위기(블룸·비네트) · 화면 글자(체력·경험치·레벨업 카드). 동작 연결표까지 코드로
- 06:54 한 번에 나온 결과: 40×30 경기장, 소품 46개, 기둥마다 횃불, 적 7종 + 보스 2종
- 07:19 게임 규칙은 스킬이 아니라 Claude 가 직접 짬: 자동 조준 마법 화살, 경험치 돌, 강화 카드 3장 중 1, 강화 5개면 포탑, 1:30 예티, 3:00 악마 군주, 5분 버티면 승리. 효과음도 코드로
- 07:46 막힌 곳 3군데(유니티 기본 상식): 바닥 충돌체 없음(플레이어가 1,129m 낙하) · 화살·줍는 물건에 물리 부품 없음(처치 0) · 편집 화면에서 채운 색이 플레이 때 비어 경험치 돌이 분홍 공. Claude 가 원인 찾아 고침
- 08:20 유니티 창이 가려지면 게임이 멈춤 — 죽은 걸로 착각 주의
- 08:30 자동 조종 판: 143초 생존, 레벨 8, 처치 163. 윈도우 빌드 성공(106MB, 1분) — 그러나 실행하면 `level0 is corrupted` 로 바로 죽음. 미해결
- 08:56 자동: 설치·프로젝트·경기장·길찾기·조명·화면 글자·게임 코드·빌드. 사람: 로그인·확인창·방향. 안 해 주는 것: 게임 규칙·그림·난이도(Claude 가 판을 돌리며 맞춤, 처음엔 23초 만에 죽어 6번 손봄)
- 09:22 스킬 31개의 공통점 3개: ① 첫 줄에 "이럴 때 써라" 조건 ② 긴 자료는 참고 폴더로, 본문엔 시킬 것만(25줄~543줄) ③ 큰 흐름 스킬은 직접 하지 말고 아래 스킬에 넘김
- 10:03 홍보 — 한글 치트시트·스킬 뼈대·게임 프로젝트는 오픈톡에서

## 걸러 들어야 할 부분

- 영상 설명: 밸런스·생존 시간은 "촬영용 자동 조종 기준 실측". 사람이 해 본 수치가 아니다.
- 최종 빌드 파일이 실행되지 않았다. "게임까지 한 줄로" 라는 제목과 달리 배포 가능한 결과는 아니다.
- 스킬 개수(31 → 33)와 라이선스 조건은 촬영일 기준이다. 9월 25일부터 저장소는 공식 플러그인 설치도 권한다고 영상 설명에 적혀 있다.
- 끝부분은 자료 배포 홍보다.

## 본 프로젝트와의 접점

- 그림 한계의 실례다. 코드로 그린 픽셀도, 무료 도트 팩을 붙인 판도 볼품이 없었다. 그래서 3D 로 바꾸고 무료 3D 팩(CC0)을 썼다. 픽셀 중세 판타지를 만든다면 쓸 만한 픽셀 그림 재료를 먼저 구해야 한다.
- 스킬 작법 공통점 3개(조건 붙은 첫 줄 · 참고 폴더 분리 · 아래 스킬에 넘기기)는 우리 skill-creator 규칙과 같은 방향이다.
- 이 컴퓨터는 WSL 이라 유니티는 윈도우 쪽에 깔아야 한다. WSL 안의 Claude 가 윈도우 유니티를 조종하는 일은 확인하지 않았다.
