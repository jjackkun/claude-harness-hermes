에이전트는 회사 직원처럼 뽑고, 말로 일을 맡깁니다

소우주(하네스가 깔린 프로젝트)에는 "명부" 가 하나 있습니다. 거기에 사람 대신 일할 에이전트를 올려 두고, 세션에서 평소처럼 말하면 됩니다. 명령어를 외울 필요는 없습니다.

한 줄로: 조직표를 정하고 → 직원을 뽑고 → 누가 맡을지 찾고 → 일을 시키고 → 끝났는지 기계가 잰다.

1

먼저 조직표를 정합니다 (한 번만)

비유 회사에 부서·직급이 없으면 채용 공고를 낼 수 없습니다.

분야(백엔드·QA…) · 직급(리드·담당…) · 조직(선적·공통…) 세 가지를 정해 두면, 에이전트는 이 세 값만 갖습니다. 정해 두지 않으면 채용이 거부됩니다.

우리 조직은 백엔드·프론트엔드·QA, 직급은 리드·담당, 조직은 선적이랑 공통이야.
2

직원을 뽑습니다

비유 입사하면 사원증(id)과 빈 이력서(SOUL.md)가 나옵니다. 처음엔 수습입니다.

이름은 겹치면 안 됩니다. 이력서 — 이 에이전트가 무엇을 맡고 무엇을 하지 않는지 — 는 사람이 씁니다. 에이전트가 자기 소개를 쓰지 않습니다.

선적 담당 QA 한 명 뽑아. 이름은 선적QA.
선적QA 수습 끝났어, 정식으로 올려.
3

누가 맡을지 찾습니다

비유 "이거 누구 담당이지?" 라고 물으면 조직표에서 찾아 줍니다. 없으면 "없습니다, 뽑으셔야 합니다" 라고 합니다.

맞는 사람이 없을 때 아무나 고르지 않습니다. 그게 이 시스템의 약속입니다.

명부 보여줘.
이 결제 버그 누가 맡지?
4

일을 시킵니다 — 두 가지 방법

비유 "지금 좀 해 줘"(소환) 와 "이 조건 되면 끝, 금요일까지"(인계) 는 다릅니다.

소환은 그 에이전트 명의로 세션을 하나 띄워 바로 시킵니다. 빠르지만 "됐다" 는 말을 믿어야 합니다.
인계는 봉투에 무엇을 · 무엇이 되면 끝 · 언제까지 를 적어 넘깁니다. 끝났다고 하면 기계가 그 조건을 다시 잽니다. 기준이나 기한을 말하는 순간 자동으로 인계가 됩니다.

선적 조회 화면 회귀 테스트, 선적QA 한테 지금 넘겨.
이 결제 리팩터 선적QA 한테 인계해. 회귀 테스트 통과하면 끝이고, 금요일까지.
5

모든 일은 장부에 남습니다

비유 누가 뽑혔고, 누가 무엇을 맡았고, 끝났는지 — 회사 인사 기록처럼 지워지지 않습니다.

입사·소환·인계는 전부 검증된 경로로만 기록됩니다. 그래서 에이전트가 자기를 다른 사람으로 속이거나 기록을 손으로 꾸밀 수 없습니다. "했다" 는 말은 주장으로 적히고, 인계였다면 기계가 조건을 다시 재서 검증값을 따로 적습니다. 은퇴시켜도 기록과 이력서는 남고, 복직도 됩니다.

지금 나 누구야?
선적QA 은퇴시켜. (되돌리기 어려운 일이라 한 번 되묻습니다)

  4. 에이전트소환된 세션에서 일함

사람 몫은 놋쇠색 하나뿐입니다. 나머지는 말하면 뒤에서 돌아갑니다.
