# 스킬 주입의 "도움 판정" 이 대부분 이뤄지지 않고, 이뤄지면 거의 다 "도움" 이다

> 출처: `docs/exec-plans/completed/2026-09-22-skill-yield-judged.md` §3

## 문제

- **판정 범위**: 공장 주입 2,879 중 판정 1,102(38%). 세션 605 중 판정이 한 번이라도 있는 세션은 **15**.
  zeroday 17/1,227 · terminal-shipping 2/308. 판정은 몇 개의 긴 세션에 몰려 있다.
- **판정 포화**: 판정된 것의 96% 가 도움(공장 helpful 1,054 · noop 47). `hermes-correlate.py` 는 스킬 키워드와 세션 도구 활동이
  2개 이상 겹치면 도움인데, 긴 세션은 도구 활동 낱말이 많아 거의 언제나 넘는다.
- 결과: 도움률로 "쓸모없는 스킬" 을 가려낼 수 없다. 2026-09-22 강등 기준을 판정 기반으로 고친 뒤 강등 후보는 11곳 모두 0.

## 먼저 잴 것

1. 판정 없는 590 세션은 어떤 세션인가 — 헤드리스(`claude -p`, `HERMES_DISABLED`) · Stop 훅이 안 돈 세션 · 대화 기록 경로 불일치 중 무엇인지.
2. 판정이 세션 길이와 얼마나 상관 있는가(짧은 세션 · 긴 세션의 helpful 비율).

## 고칠 때 후보

- 판정 규칙: 겹침을 흔한 낱말 제외 + 스킬 길이 대비 비율로(`backlog/crystallize-stability-score.md` 후보 1 과 같은 일).
- 판정 범위: Stop 훅 밖(세션 압축 시점 · 다음 세션 시작 시 이전 세션 몫)에서도 상관을 돈다.
