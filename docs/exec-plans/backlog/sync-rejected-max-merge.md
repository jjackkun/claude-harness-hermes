# 동기화가 거부(-1)를 대기(0)로 되돌린다

> 출처: 2026-11-19 결정화 검사 판정 계획 검토(planner-lite) 에서 발견. 그 계획의 범위 밖.

## 문제

`scripts/hermes_sync_learning.py:164` 는 `pattern_count.crystallized` 를 `max(crystallized, excluded.crystallized)` 로 합친다.
한 컴퓨터에서 거부(-1)한 패턴이 다른 컴퓨터의 대기(0)를 만나면 0 이 이긴다.
그래서 거부한 패턴이 다른 컴퓨터에서 다시 결정화될 수 있다.
이제 검사 판정의 `covered`(게이트가 이미 막음)도 -1 을 쓰므로, 같은 경로로 글 규칙이 되살아날 수 있다.

## 할 일 후보

- 병합 규칙을 "0 이 아닌 값이 이긴다(1 > -1 > 0)" 로 바꾸고 시험으로 고정한다. 실측부터: 운반된 pattern 파일 중 -1 이 몇 개인지.
