# 설치가 소우주에서 다듬은 scripts/check-secrets.py 를 공장판으로 덮는다

> 작성일: 2026-10-20
> 목적: 전파 때마다 소우주가 맞춘 비밀값 검사기 면제 목록이 사라지는 일을 없앤다.
> 근거: `docs/exec-plans/completed/2026-10-20-ui-prototype-skill.md` §7 (전파 중 발견)

## 개요

terminal-shipping 은 `scripts/check-secrets.py` 를 자기 저장소에 맞게 고쳐 커밋해 두었다(면제 경로 주석, `^tests/` 통째 면제 금지 등).
설치기가 이 파일을 공장판으로 다시 쓰면서 작업 트리에 146줄 차이가 생겼고, 원격에는 사람이 손으로 "이 저장소 판에 공장 0397dcb 만 합친다" 는 커밋(`21a81547`)을 올려야 했다.

- 2026-10-20 ui-prototype 전파에서는 이 파일을 커밋에서 뺐다(설치 전부터 이미 덮인 상태였음).
- 같은 저장소의 hermes 스크립트 7개도 작업 트리 사본과 원격판이 갈라져 있다 — 같은 원인인지 확인 필요.

## 후보

1. `install_factory_file` 공존 판정에 "소우주가 커밋으로 바꾼 파일" 을 넣어 `.factory-new` 로 세워 두기 (덮지 않기).
2. 또는 check-secrets 면제 목록을 소우주 설정 파일로 빼서 본문은 공장판, 면제만 소우주 몫으로.
