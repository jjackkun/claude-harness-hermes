# tasks-pane-mod — 모드 띠에 `[ 배경 작업 ]` 버튼을 더한다

> 작성일: 2026-10-19
> 목적: 배경으로 돌린 긴 명령(빌드·전체 시험·배포)이 지금 어디까지 왔는지를 패널로 보이게 한다.

## 배경

사용자 요청(2026-10-19, jj-agent-room 세션): 설치 파일 빌드를 배경으로 돌리는 동안
"언제 끝나는지를 모르니 보고 싶다" — 지금 띠는 `[ 도구 호출 ][ 에이전트 명부 ][ 파일 ]` 세 개이고,
여기에 배경 작업 버튼을 더해 달라는 것.

지금 볼 수 있는 길은 셋뿐이고 모두 불편하다.

- `/tasks` — 목록은 보이지만 진행(로그 끝부분)은 안 보인다.
- `! tail -f <로그>` — 경로를 사람이 알아야 하고 프롬프트를 차지한다.
- 에이전트가 Monitor 로 단계마다 한 줄씩 알려 주는 것 — 단계 사이(몇 분)는 조용하다.

## 무엇을 만드는가

모드 `tasks-pane` 하나(기존 세 모드와 같은 구조: `assets/skills/tasks-pane/`, 전역 선택 프리셋 `mods` 로 깔림).

| 여는 방법 | 하는 일 |
|-----------|---------|
| `/tasks-pane`, 띠의 `[ 배경 작업 ]` | 이번 세션에서 배경으로 돌린 작업을 줄마다 하나씩: 설명 · 걸린 시간 · 상태(`실행`/`끝`) · 출력 파일의 마지막 몇 줄. 줄을 고르면 그 작업의 출력 끝부분을 더 길게 |

- 띠 버튼은 배경 작업이 하나라도 있을 때만 그린다(없으면 띠가 지금 그대로).
- 실행 중인 작업 수를 버튼에 붙인다: `[ 배경 작업 2 ]`.

## 어떻게 아는가(설계 기록 `docs/design-docs/claude-code-mods.md` 기준)

- 모드가 받는 이벤트: `session.start` · `tool.call` · `ui.render` · `command.run`(같은 문서 §패널과 띠, `tool-calls-pane/hooks/register.tsx`).
- `tool.call` 에서 `Bash` 의 `run_in_background: true` 호출을 고른다. `next(e)` 가 돌려주는 결과 글에
  작업 ID 와 출력 파일 경로가 있다("Command running in background with ID: … Output is being written to: …") —
  이 둘을 상태(`$.state`)에 쌓는다.
- 진행은 출력 파일을 `$.process.run(['tail', '-n', N, path])` 로 주기적으로 읽어 보인다(패널이 열려 있을 때만).
- `Agent`(배경 실행)와 `Monitor` 도 같은 방식으로 담을 수 있는지 함께 본다.

## 착수 전 확인할 것(모르는 것)

1. **끝났다는 신호가 모드에 오는가** — 배경 작업의 완료 알림(종료 코드 포함)이 `tool.call` 밖의 이벤트로 오는지 문서·실측으로 확인.
   오지 않으면 대안: 출력 파일이 일정 시간 안 자라면 `조용함` 으로만 보이고 `끝` 은 단정하지 않는다(거짓 `끝` 금지).
2. 결과 글의 문구가 엔진 판마다 같은지 — 정규식 하나에 기대면 문구가 바뀔 때 조용히 빈 패널이 된다. 못 읽으면 "출력 경로를 못 찾음" 을 보인다.
3. 출력 파일이 세션 임시 폴더(`/tmp/claude-…/tasks/<id>.output`)에 있어 다른 세션·사용자 것을 읽지 않는지 — 이번 세션의 `tool.call` 에서 받은 경로만 읽는다.
4. 큰 출력 — 끝부분만 읽는다(`tail`), 줄 길이도 자른다.

## 함께 고칠 곳

- 패널 이름 목록 `ALL_PANES`(`[ 전체 닫기 ]`)가 세 모드에 각각 적혀 있다 → 네 곳으로 늘어난다. 이번에 한 곳으로 모을지 같이 정한다.
- `docs/design-docs/claude-code-mods.md` 의 "만든 모드" 표에 한 줄.
- 공장 시험(`tests/run-all.sh`)의 모드 검사(`claude plugin validate`, 띠 버튼 시험)에 네 번째 모드를 더한다.

## 완료 조건(이 문서를 계획으로 옮길 때 명령으로 바꾼다)

- 배경 `Bash` 하나를 돌리면 띠에 `[ 배경 작업 1 ]` 이 뜨고, 패널에 그 작업의 출력 끝부분이 갱신된다.
- 배경 작업이 없는 세션에서는 띠가 지금과 같다(세 버튼).
- 다른 세 모드의 버튼이 가려지지 않는다(`next(e)` 로 이어 그림).
