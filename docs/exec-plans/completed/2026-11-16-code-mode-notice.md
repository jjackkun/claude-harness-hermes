# 2026-11-16-code-mode-notice — 설치가 끝날 때 Code Mode 가 꺼져 있으면 알린다

## 1. 동기 (Why)

- Code Mode(클로드 코드 2.1.323+ 실험 기능)는 사용자 설정(`~/.claude/settings.json` 의 `env`)에서만 켜진다. 프로젝트 설정은 무시된다 — 컴퓨터마다 사람이 한 줄을 넣어야 한다.
- 공장은 사용자 전역 설정을 고치지 않는다(전역 규칙 1). 그래서 새 컴퓨터에서 공장을 받으면 꺼진 채로 남고, 아무도 알려 주지 않는다(2026-11-16 사용자 지적).
- 공장 훅·모드가 Code Mode 와 함께 도는 것은 실측했다(`docs/audits/2026-11-16-code-mode-hooks.md`).

## 2. 목표 (What — 검증 가능한 형태)

- [x] G1 `setup.sh`·`update-all.sh`(claude 대상)가 끝날 때, 클로드 코드가 2.1.323 이상이고 Code Mode 설정이 없으면 켜는 법 한 줄을 띄운다 — 검증: `tests/code-mode-notice-test.sh`
- [x] G2 이미 켰거나(`1`) 일부러 껐으면(`0`, 환경변수나 사용자 설정) 아무것도 띄우지 않는다 — 검증: 같은 시험
- [x] G3 클로드 코드가 2.1.323 보다 낮으면 "올리면 켤 수 있다" 한 줄, 클로드 코드가 없으면 침묵 — 검증: 같은 시험
- [x] G4 사용자 설정 파일을 읽기만 하고 고치지 않는다 — 검증: 시험이 파일 해시를 앞뒤로 비교
