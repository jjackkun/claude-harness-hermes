# 2026-09-21-manifest-tracking-warn — 설치 목록이 git 에 안 들어가는 소우주를 보이게 한다

## 1. 동기 (Why)

설계 전제(I-02)는 "설치 목록(`.claude/.factory-manifest.json`)은 커밋된다" 인데, 프로젝트 자체 `.gitignore` 가 `.claude/*` 를
통째로 무시하면 그 전제가 조용히 깨진다. 공장이 넣는 무시 블록에는 그 파일의 예외가 없다.

실측(2026-09-21, 12곳 중 git 저장소 11곳):

| 상태 | 곳 |
|---|---|
| 추적됨 | 9 |
| **무시돼 추적 안 됨** | **2 — ai-create · kis-trading** |
| git 저장소 아님 | 1 (teulankkae) |

그 2곳은 다른 컴퓨터에서 clone 하면 `harness-doctor` 가 "매니페스트 없음" 으로 진단 불가, 공존 설치는 base 를 몰라 판정 불가 갈래로 간다.
지금은 **아무도 그 사실을 말해 주지 않는다.**

## 2. 목표 (What — 검증 가능한 형태)

- [x] 목표 1 — `harness-doctor` 가 "매니페스트가 git 에 추적되지 않음" 을 진단 항목으로 낸다(정보 — `ok` 를 거짓으로 만들지 않는다)
  — 검증: `bash tests/manifest-tracking-test.sh` (a) 무시되는 픽스처에서 그 줄이 나오고, 추적되는 픽스처에서는 안 나온다
- [x] 목표 2 — 설치기가 설치 끝에 같은 사실을 **경고**로 보고한다(조용히 넘어가지 않는다)
  — 검증: 같은 테스트 (b) 픽스처 설치 로그에 경고 문구
- [x] 목표 3 — 판정은 `git check-ignore` 로 한다(파일 존재·추적 여부·무시 규칙을 실제 git 에 묻는다). git 저장소가 아니면 조용히 넘어간다
  — 검증: 같은 테스트 (c) git 아닌 디렉터리에서 rc 0·출력 없음
- [x] 목표 4 — 공장 무시 블록에 `!.claude/.factory-manifest.json` 예외를 넣는다. **순서 의존을 인정한다** — 프로젝트 규칙이 뒤에 오면
  예외가 덮이므로 이 한 줄로는 부족하고, 그래서 목표 1·2 의 보고가 본체다 — 검증: 같은 테스트 (d) 예외 줄 존재 + 덮이는 경우 경고가 여전히 나온다
- [x] 목표 5 — 등록·폐로 — 검증: `bash tests/run-all.sh --check-orphans` · `bash tests/harness-doctor-test.sh` · 전체 스위트

## 3. 비목표 (Out of Scope)

- 프로젝트의 `.gitignore` 를 공장이 고치는 것 — 그 프로젝트의 선택이다. 보고까지만 한다.
- `.claude/skills|agents|rules` 사본의 추적 여부 — 같은 선택의 결과이고, clone 뒤 재설치 한 번이면 복구된다(설치 안내에 한 줄).
- 매니페스트를 다른 경로로 옮기는 것 — 경로는 I-02 가 정했다.

## 7. 발견·예외

- **기존 시험이 반대 방향을 못 박고 있었다.** `copy-install-test.sh` 가 "manifest 는 gitignore 마커에 **없음**" 을 단언했다
  (문자열 언급 여부로). 의도는 "무시되면 안 된다" 인데, 언급 금지로 적어 두면 프로젝트가 `.claude/*` 를 무시할 때 목록이 조용히
  빠지는 바로 그 사고를 막지 못한다. 바로 윗줄의 `factory.json` 은 이미 **예외 줄이 있는지**를 단언한다 — 그 형태로 통일하고,
  `git check-ignore` 로 실제 무시 여부까지 물었다. 56/56.
- 실 소우주 확인: `ai-create` 1건 · `kis-trading` 1건 · `zeroday-frontend` 0건 — 앞서 잰 2곳과 정확히 일치한다.
- 예외 줄은 순서에 진다(프로젝트 규칙이 뒤면 덮임). 그래서 시험 (d) 가 "덮여도 잡는가" 와 "순서를 되돌리면 사라지는가" 를 둘 다 고정한다.

## 8. 회고 (완료 시 작성)

- 잘된 것: 무시 규칙 해석을 우리가 하지 않고 `git check-ignore` 에 맡겼다. 순서·부정 규칙을 직접 파싱했으면 틀렸을 자리다.
- 잘못된 것: 없음 특기. (기존 시험과의 충돌은 의도 확인 뒤 형태를 통일해 해소)
